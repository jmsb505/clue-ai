# Clue AI — Personal Job Search

A local-first job-search tool for one person. The product is in definition and feasibility planning; application code has not started.

The app is intended to search a broad set of free job feeds, APIs, and registered public job pages. Scrapling is the selected crawler for public HTML job and career pages. TypeSafe Jev evaluates candidate-to-listing fit, with a hard spend cap of $5 per month; all other services and data sources must be free. The app ranks and explains listings for the user to review, but does not apply on their behalf.

The first search profile focuses on fully remote roles explicitly eligible for work from Milan/Italy. Search geography remains configurable. CV, profile, preferences, and saved results are intended to stay on the user's device, with only the minimum fit data sent to Jev.
